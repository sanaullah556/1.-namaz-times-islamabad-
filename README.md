# Namaz Times — Islamabad

A small learning project that shows the daily prayer (Namaz) times for Islamabad, Pakistan.

## What it does
- Fetches prayer timings from the public **Aladhan API** (REST + JSON)
- Shows the five daily prayer times for the current day
- Caches timings in a small database so repeat visits load faster

## Tech used
- React + TypeScript (frontend)
- TypeScript server with a SQLite database (Drizzle ORM)
- Public REST API integration: https://api.aladhan.com/v1
